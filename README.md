# 입고 예약 보드 v0.27

## 반영 내용
- 상단 로고 다시 적용
- 로고를 제목과 같은 라인에 더 크게 표시
- 브랜드 선택 필터 유지: 오늘/내일 라인 오른쪽 `브랜드 전체`
- 고객사/발주번호 검색 유지
- 시트 M열 층 기준 유지
- 전체/완료/미입고/승인대기 필터 유지
- 컨테이너 문구만 제거: `컨테이너 20FT` → `20FT`

## v0.27 변경

- 시트 수식/M열 층 자동입력은 건드리지 않음


## v0.27
- 예약 슬롯 클릭 시 시트3 발주입고 상세 내역 표시
- 시트3 A/P/Q/T열 사용: 발주번호 / 제품 / 제품명 / 수량
- 숫자 발주번호만 상세 매칭
- 퀵/추후기재/추후입력 등 비숫자 발주번호는 발주번호 등록 후 확인 안내
- 매칭 내역이 없으면 '상세 내역 없음' 표시


## v0.27

- `퀵`, `추후기재`, `추후입력` 등은 기존처럼 상세 매칭 제외입니다.


## v0.27

## v0.27 변경
- 세컨드마켓 상세 조회 조건을 숫자 발주번호 검사보다 먼저 처리하도록 수정했습니다.

- 공백 및 숨은 문자 보정을 강화했습니다.
